#  JavaScript

##  O que é JavaScript?

JavaScript é uma linguagem de programação utilizada para criar páginas e aplicações web interativas e dinâmicas.

Ela trabalha principalmente em conjunto com HTML e CSS no desenvolvimento web.

##  Para que serve?

JavaScript pode ser utilizado para:

- Criar interações em páginas web
- Manipular elementos HTML
- Validar formulários
- Criar animações e efeitos
- Trabalhar com APIs
- Manipular dados
- Desenvolver aplicações web
- Criar aplicações com Node.js

##  HTML, CSS e JavaScript

| Tecnologia | Função |
|---|---|
| HTML | Estrutura da página |
| CSS | Estilo e aparência |
| JavaScript | Interação e comportamento |

## Principais conceitos

- **Variáveis:** `let`, `const` e `var`
- **Condicionais:** `if`, `else` e `switch`
- **Laços de repetição:** `for`, `while` e `do...while`
- **Funções:** blocos de código reutilizáveis
- **Arrays:** listas de informações
- **Objetos:** estruturas que armazenam dados
- **DOM:** manipulação dos elementos HTML
- **Eventos:** ações como `click`, `submit` e `mouseover`
